# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun bounty
[u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)

`main.py` (Python 3.13, standard library only) writes one original roast
line to `/output/entry.txt` — a one-line roast of the wireless earbuds
used every day, whose left ear always dies first.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
